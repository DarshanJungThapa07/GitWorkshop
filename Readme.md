1. DOwnload git 
2. Make a repo in github
3. git init . : for initialization
4. git remote add origin <add your url> - to connect to github repo
5. git add . : to make your files ready to staging 
6. git commit -m "your commit message" : to add your commit message
7. git push --set-upstream origin main or git push -u :to push your code to github
8. git branch : to see all the branches
9. git checkout -b "branchName" : to make another branch
